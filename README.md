# 拼音记住

免登录、手机优先、可离线使用的汉字拼音练习。此仓库仅保存公开网页的静态发布资源，不保存用户学习记录。用户记录位于各自浏览器的 IndexedDB 中。

首次联网等到“离线已就绪”，即可添加到手机主屏幕。无需注册账号或提供相机、麦克风、定位权限。

字库：Unicode Unihan 15.1.0，《通用规范汉字表》8105字范围，常规鼻韵母3213条字音，另含2条特殊音节；3169条可练，46条待补语境。

例词数据来自 [CC-CEDICT/MDBG](https://www.mdbg.net/chinese/dictionary?page=cedict)，遵循 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。Unicode数据遵循 [Unicode许可](https://www.unicode.org/license.txt)。来源版本与筛选说明见 data/provenance.json。

本站不依赖 ChatGPT Sites。不同地区网络仍可能影响GitHub Pages可达性，以目标设备实测为准。
